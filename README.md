# AI-based Network Intrusion Detection using CICIDS2017

## Problem Statement

Modern computer networks experience increasingly sophisticated cyberattacks. Traditional signature-based intrusion detection systems struggle to detect previously unseen attacks. This project investigates the use of machine learning techniques for network intrusion detection using the CICIDS2017 dataset.

---

## Dataset

Canadian Institute for Cybersecurity (CICIDS2017)

Approximately 2.8 million records

79 network traffic features

15 attack categories

---

## Exploratory Data Analysis

EDA included:

- Missing value analysis
- Duplicate analysis
- Dataset statistics
- Attack distribution
- Correlation analysis
- Outlier analysis
- Feature engineering

---

## Baseline Model

Algorithm:

Random Forest Classifier

Evaluation Metrics:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

The baseline model achieved excellent performance and will be compared with additional models in Module 24.
